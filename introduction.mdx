## What is RuedaPro UNIPAZ?

RuedaPro UNIPAZ is a comprehensive web platform designed to manage, evaluate, and publish results of the Engineering Projects Wheel event at UNIPAZ University. It streamlines the entire lifecycle of student project evaluations, from registration to final results publication.

## Key Features

<AccordionGroup>
  <Accordion title="Multi-Role Authentication" icon="lock">
    Secure role-based access control with three user types: Students, Teachers, and Administrators. Each role has specific permissions and dedicated dashboards powered by Supabase authentication.
  </Accordion>
  
  <Accordion title="Project Management" icon="folder-tree">
    Complete project lifecycle management including registration, evaluator assignment, status tracking, and student-project associations. Projects are organized by semester, year, and category.
  </Accordion>
  
  <Accordion title="Evaluation System" icon="clipboard-check">
    Structured evaluation rubrics for teachers with scoring across multiple criteria. Teachers can provide detailed observations and final scores, with automatic average calculation across multiple evaluators.
  </Accordion>
  
  <Accordion title="Results Gallery" icon="chart-line">
    Public-facing results page displaying historical rankings and project achievements. Filter by semester, year, and category to explore past winners and standout projects.
  </Accordion>
  
  <Accordion title="Row-Level Security" icon="shield-halved">
    Advanced database security with Supabase RLS policies ensuring users can only access data they're authorized to view. Public users see only evaluated projects, while authenticated users have role-specific access.
  </Accordion>
  
  <Accordion title="Responsive Design" icon="mobile-screen">
    Mobile-friendly interface with light and dark theme support. Accessible navigation and optimized layouts for all device sizes.
  </Accordion>
</AccordionGroup>

## Technology Stack

RuedaPro UNIPAZ is built with modern web technologies:

- **Frontend**: Vanilla JavaScript with a custom SPA router
- **Backend**: Supabase (PostgreSQL database, authentication, row-level security)
- **Styling**: Custom CSS with CSS variables for theming
- **Icons**: Font Awesome 6
- **Hosting**: Static site deployment compatible
